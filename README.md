# Security Portfolio

Hands-on web application security practice, documented as I go.

> **Scope & ethics:** All testing is performed only against my own self-hosted,
> intentionally vulnerable labs (e.g. OWASP Juice Shop), explicitly authorized
> practice targets (Hack The Box, PortSwigger Web Security Academy), or public
> bug-bounty / vulnerability-disclosure programs I am enrolled in — and, for those,
> only within their published scope and policy. Never against systems I do not own
> or do not have permission to test. Writeups for live programs are anonymized and
> cover methodology only, with no reproducible attack paths, while the program is
> ongoing or under a coordinated-disclosure window.

## Contents

- **`juice-shop/`** — OWASP Juice Shop (self-hosted) assessment
  - `writeups/` — individual vulnerability writeups, each reproduced and
    documented by hand, in my own words.
- **`bug-bounty/`** — methodology writeups from authorized VDP / bug-bounty
  engagements. Anonymized; focused on recon, scope discipline, and feasibility
  judgment rather than live target details.
  - `writeups/` — one writeup per engagement or theme, in my own words.

## Approach

For every finding I reproduce it myself, explain the root cause, assess the
impact, and write the remediation — not just run a tool. Writeups are written in
English to practice clear technical communication.

## Goals

Aspiring offensive security engineer, focused on web application penetration
testing. Building hands-on experience toward a junior pentester role, with OSCP
as a longer-term target.
